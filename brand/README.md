# Marca — arquivos-fonte

Originais oficiais da marca Luumu People. Não edite nem redesenhe: as variações são geradas a partir daqui.

| Arquivo | O que é | Gera |
|---|---|---|
| `luumu-people.svg` | logo oficial (mascote, balão e wordmark) | `public/brand/*` com `pnpm brand:build` |
| `email-hero.png` | ilustração oficial dos e-mails transacionais | `public/email/*` com `pnpm tsx scripts/build-email-assets.mts` |

Regras de uso (a folha só sobre o "ú", mascote decorativo, componentes `<Logo />`, `<Wordmark />` e `<Mascot />`) estão em [docs/design-system.md](../docs/design-system.md#marca).
